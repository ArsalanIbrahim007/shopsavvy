# ShopSavvy

ShopSavvy is a Final Year Project developed at Bahria University Karachi.

## Features

- Product Search
- Price Comparison
- Best Deal Recommendation
- Product Matching
- Price History Tracking
- Fake Discount Detection

## Tech Stack

Frontend:
- React.js

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Data Collection:
- Axios
- Cheerio
- Playwright (future)

AI Components:
- Product Matching
- Ranking Engine
- Discount Detection
